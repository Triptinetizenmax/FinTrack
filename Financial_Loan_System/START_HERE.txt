FINANCIAL LOAN MANAGEMENT SYSTEM — START HERE

1. Open this folder in VS Code.
2. Install requirements: python -m pip install -r requirements.txt
3. Copy .env.example to .env and set your PostgreSQL password.
4. Make sure database financial_loan_db exists and PostgreSQL is running.
5. Run: python -m uvicorn app:app --reload
6. Open http://127.0.0.1:8000
7. API docs: http://127.0.0.1:8000/docs

Do not share your .env file or real database password. This is a local educational demo, not a production banking system.
